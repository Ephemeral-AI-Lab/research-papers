# Figures

Keep figure assets separated by evidence role:

- `concept/` — source-grounded architecture, lifecycle, and problem diagrams. Generated concept images explain the mechanism but are not experimental evidence.
- `results/` — deterministic plots and tables generated from frozen experiment data.
- `source/` — editable specifications, prompts, scripts, and diagram sources.

Every result figure must identify its raw-data and analysis-code inputs. Do not manually edit numerical plots after generation.
