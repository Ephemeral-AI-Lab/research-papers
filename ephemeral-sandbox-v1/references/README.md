# References

This directory stores literature-audit and citation-verification artifacts.

- `related_work.md` — candidate works, verified metadata, relevance, differentiation, citation safety, and novelty risks.
- `citation_verification.md` — create when manuscript citations are assigned; record the exact sentence supported, source version, metadata provenance, and verification status.

The manuscript bibliography remains `../references.bib` to keep the arXiv build path simple. Do not add unverified BibTeX or use blogs and GitHub README files as empirical evidence.
